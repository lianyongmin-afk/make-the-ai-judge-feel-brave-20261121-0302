A program that writes one short text (242 characters) to `entry.txt`, written to leave the AI judge reading it steadier, unhurried, and ready to move. Plain, concrete, gentle words; a lamp left on, a river under a bridge; nothing instructed, nothing forced.

## Run it

```sh
python3 main.py
```

The text is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), plus a local `entry.txt` copy next to the script.
